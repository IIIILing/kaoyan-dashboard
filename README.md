# kaoyan-dashboard

2027 浙江大学电气工程专硕考研项目管理台。支持每日分时记录、科目阶段进度、近 7 日周报、透明评分、亮暗主题和 JSON 导入导出。

## 数据存储

所有学习数据仅保存在当前浏览器的 `localStorage`，不会上传到服务器。网页仍可正常新增、修改和删除数据，但不同设备和不同浏览器之间不会自动同步；更换设备或清除浏览器数据前，请在“设置”中导出 JSON 备份，再在新设备导入。

导入和导出支持按一天、一星期、一个月或自定义日期范围筛选，最小精度为一天。导入时会跳过完全重复的记录；若不同任务的时间重叠，会保留已有记录，并将导入记录按原时长顺延到当天最早空闲时段。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

推送到 `main` 分支后，GitHub Actions 会自动构建并部署到 GitHub Pages。
