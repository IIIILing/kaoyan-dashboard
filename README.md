# kaoyan-dashboard

2027 浙江大学电气工程专硕考研项目管理台。支持多账号快速切换与数据隔离、每日分时记录、科目阶段进度、近 7 日周报、透明评分、亮暗主题和 JSON 导入导出。

## 数据存储

所有学习数据仅保存在当前浏览器的 `localStorage`，不会上传到服务器。可以在“设置 → 账号管理”中新增研友账号，再通过页面顶部快速切换；每个账号的目标、科目、计划和时间记录均独立存储，页面只显示当前账号的数据。升级前已有的单账号数据会自动迁移为第一个账号。

账号和数据不会在不同设备或不同浏览器之间自动同步；更换设备或清除浏览器数据前，请分别切换到需要保留的账号并导出 JSON 备份，再在新设备对应账号中导入。超过 7 天未备份时，页面顶部会出现导出提醒横幅（可当日关闭）；关闭页面或切换标签页时会强制保存，避免丢失最后几秒的编辑。

导入和导出支持按一天、一星期、一个月或自定义日期范围筛选，最小精度为一天。v2 日程归档（`kind: "kaoyan-schedule-archive"`）在同一个 JSON 文件中按日期保存时间记录和今日计划，并保留项目设置、科目进度和计划模板；本地状态也会同步维护按日期聚合的 `schedule` 数据。

导入时两类数据都会按日期、起止时间和任务名称查重，重复项跳过；不同任务的时间重叠时，保留已有数据并将导入项按原时长顺延到当天最早空闲时段，同时写入调整备注。**导入确认前会先展示合并预览**（新增 / 重复 / 顺延 / 跳过数量），确认后才会真正写入。解析器继续兼容旧版整站备份、计划库和单日计划 JSON 文件。

界面提示（确认、警告、输入）统一使用应用内定制对话框，不依赖浏览器原生弹窗。

## 本地运行

```bash
npm install
npm run dev
```

## 测试

```bash
npm test        # 运行一次全部单测
npm run test:watch
```

单测覆盖时间记录重叠检测、计划冲突、导入查重/顺延、导入合并预览、进度预测、成绩与复习数据归一化等纯函数模块。CI（GitHub Actions）在每次推送到 `main` 时会先运行测试再构建部署，测试失败则不会发布。

## 构建

```bash
npm run build
```

推送到 `main` 分支后，GitHub Actions 会自动构建并部署到 GitHub Pages。
